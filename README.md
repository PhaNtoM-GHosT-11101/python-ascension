## How it works
- **Rank E → S** — like Solo Leveling. Earn XP per battle, level up, evolve shadow pet.
- **Worlds A-Z (11 Worlds):**
  1. Genesis — Variables, Types, I/O
  2. Logic Gate — If/Else, Loops, Comprehensions
  3. Function Forge — Functions, Recursion, Lambdas
  4. Data Dungeon — Lists, Dicts, Sets, Tuples
  5. OOP Colosseum — Classes, Magic Methods, Metaclasses
  6. Advanced Abyss — Decorators, Generators, Context Managers
  7. Async Void — Asyncio, Threading, GIL
  8. DSA Dungeon — Arrays, Hashing, Two Pointers, Stack/Queue (150 battles)
  9. DSA Abyss — Linked List, Trees, Graphs, Heap, DP — FAANG Hard
  10. AI Frontier — Numpy, Pandas, RAG, Chatbots, Automation
  11. System Fortress — FastAPI, SQL/Redis, Docker, Git, Pytest, Deploy

- **Battle types:** Write from scratch + Debug + Fill blanks (mix)
- **Tests:** Visible + Hidden pytest-style via Pyodide (in-browser Python, no backend)
- **Dopamine:** 2 min lesson → battle, hint (-5 XP), auto-bookmark + resource on 3 fails → Revise Dungeon (forgetting curve)
- **No lag:** Pyodide + Monaco, lazy-load, switchable themes (Dark/Anime/Pixel/Hacker), lo-fi toggle, Vim mode
- **Streak:** Daily reminder + lose XP if skip, 15 min daily quest
- **Goal:** FAANG DSA > AI > Fullstack — 3 month timeline
